# Popper

anchor의 상대적인 위치에 콘텐츠를 띄우는 컴포넌트

## Import

```js
import { Popper } from '@/components/_share/Popper';
```

## Usage

### Basic Popper

- `children`: anchor 주변에 띄울 콘텐츠
- `anchorReference`: popper의 위치를 설정할 때, 어떤 anchor prop을 참조할지 결정 (default: `'anchorEl'`)
  - `'anchorEl'` 인 경우: `anchorElRef`, `anchorOrigin`(optional) prop을 추가해야 함
  - `'anchorPosition'` 인 경우: `anchorPosition` prop을 추가해야 함
- `anchorElRef`: anchor 요소 참조 객체
