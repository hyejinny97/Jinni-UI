## Duration Tokens 접근 및 사용

### In CSS

- css 내장 `var()` 함수를 사용해 root 요소에 등록된 duration 변수 가져와 사용

  ```css
  .classname {
    transition-property: opacity;
    transition-timing-function: ease;
    transition-duration: var(--jinni-duration-extra-long4);
  }

  .classname {
    animation-name: appear;
    animation-timing-function: ease;
    animation-duration: var(--jinni-duration-extra-long4);
  }
  ```

  ```css
  .classname {
    transition: opacity var(--jinni-duration-extra-long4) ease;
  }

  .classname {
    animation: appear var(--jinni-duration-extra-long4) ease;
  }
  ```

### In JSX

#### 1. Inline style에서 CSS 변수 `var()` 사용

```jsx
const App = () => {
  return (
    <>
      <p
        style={{ transition: 'opacity var(--jinni-duration-extra-long4) ease' }}
      >
        text
      </p>
      <p style={{ animation: 'appear var(--jinni-duration-extra-long4) ease' }}>
        text
      </p>
    </>
  );
};
```

#### 2. `useJinni` hook

```jsx
import useJinni from '@/hooks/useJinni';

const App = () => {
  const { duration } = useJinni();

  return (
    <p style={{ transition: `opacity ${duration['extra-long4']} ease` }}>
      text
    </p>
  );
};
```

#### 3. `useStyle` hook

```jsx
import useStyle from '@/hooks/useStyle';

const App = () => {
  const style = useStyle({
    animationName: 'appear',
    animationTimingFunction: 'ease',
    animationDuration: 'extra-long4'
  });

  return <p style={style}>Appear Text</p>;
};
```

### JinniUI Components

- JinniUI에서 제공하는 컴포넌트 전부 `style` prop(`StyleType`, extended style type)을 받음
- `style` prop의 값은 내부적으로 `useStyle` 훅으로 처리해주고 있음
- 따라서, JinniUI 컴포넌트에 duration tokens를 적용하고 싶으면 `style` prop에 바로 작성하면 됨

```jsx
<Avatar
  style={{
    transitionProperty: 'opacity',
    transitionTimingFunction: 'ease',
    transitionDuration: 'extra-long4'
  }}
>
  N
</Avatar>
```

## Customization

### Jinni UI - Duration (기본값)

- `createDesignSystem` 함수의 `duration` props를 설정하지 않을 경우, 기본적으로 Jinni UI의 Duration이 설정됨

  ```jsx
  const designSystem = createDesignSystem();
  ```

  ```jsx
  const designSystem = createDesignSystem({
    duration: DEFAULT_DURATION
  });
  ```

### Customize Duration

- `createDesignSystem` 함수의 `duration` props로 설정된 값은 기존 Jinni UI의 `duration`에 덮어 씌워지게 됨
- 즉, `DesignSystemType`의 `duration`에 존재하는 key 값을 설정하면 기존 값이 변경되고, `DesignSystemType`의 `duration`에 존재하지 않는 key 값을 설정하면 속성이 새로 추가됨

  ```tsx
  interface DesignSystemType {
    easing: {
      'short1': string;
      'short2': string;
      'short3': string;
      'short4': string;
      'medium1': string;
      'medium2': string;
      'medium3': string;
      'medium4': string;
      'long1': string;
      'long2': string;
      'long3': string;
      'long4': string;
      'extra-long1': string;
      'extra-long2': string;
      'extra-long3': string;
      'extra-long4': string;
    }
    ...
  }
  ```

#### 1) 기존 duration 값 변경

```jsx
const designSystem = createDesignSystem({
  duration: {
    short1: '80ms'
  }
});
```

#### 2) 새로운 duration 속성 추가

1. 새 duration 속성 추가

   ```jsx
   const designSystem = createDesignSystem({
     duration: {
       standard: '300ms',
       'entering-screen': '225ms',
       'leaving-screen': '195ms'
     }
   });
   ```

2. 유의할 점

   - 이 경우 `useStyle` 훅이나 JinniUI Component의 style(extended style type)에서는 새로 추가한 duration 속성을 사용할 수는 없음

   ```jsx
   // ⭕ 가능
   import useJinni from '@/hooks/useJinni';

   const App = () => {
     const { duration } = useJinni();

     return (
       <>
         <p
           style={{ transition: 'opacity var(--jinni-duration-standard) ease' }}
         >
           text
         </p>
         <p style={{ transition: `opacity ${duration['standard']} ease` }}>
           text
         </p>
       </>
     );
   };
   ```

   ```jsx
   // ❌ 불가
   import useStyle from '@/hooks/useStyle';

   const App = () => {
     const style = useStyle({
       animationName: 'appear',
       animationTimingFunction: 'ease',
       animationDuration: 'standard'
     });

     return (
       <>
         <p style={style}>text</p>
         <Avatar
           style={{
             transitionProperty: 'opacity',
             transitionTimingFunction: 'ease',
             transitionDuration: 'standard'
           }}
         >
           N
         </Avatar>
       </>
     );
   };
   ```
