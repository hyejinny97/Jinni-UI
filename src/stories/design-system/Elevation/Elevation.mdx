## JinniUI Elevation Tokens

- elevation: 계층(높낮이)
- 0부터 24까지 총 25가지의 elevation tokens
- theme mode에 따라, elevation을 나타내는 수단의 차이가 있음
  - 'light' mode인 경우, `box shadow`를 통해 elevation을 나타냄
  - 'dark' mode인 경우, `box shadow` + `white overlay`를 통해 elevation을 나타냄

## Elevation Tokens 접근 및 사용

### In JSX

#### 1. className에 `elevation-{elevation-level}` 작성

```jsx
<Avatar className="elevation-10">N</Avatar>
<p className="elevation-10">text</p>
```

#### 2. `useJinni` hook

```jsx
import useJinni from '@/hooks/useJinni';

const App = () => {
  const { elevation } = useJinni();

  return <p style={{ ...elevation[10] }}>text</p>;
};
```

#### 3. `useStyle` hook

```jsx
import useStyle from '@/hooks/useStyle';

const App = () => {
  const style = useStyle({ elevation: 10 });

  return <p style={style}>text</p>;
};
```

### JinniUI Components

- JinniUI에서 제공하는 컴포넌트 전부 `style` prop(`StyleType`, extended style type)을 받음
- `style` prop의 값은 내부적으로 `useStyle` 훅으로 처리해주고 있음
- 따라서, JinniUI 컴포넌트에 elevation tokens를 적용하고 싶으면 `style` prop에 바로 작성하면 됨

```jsx
<Avatar style={{ elevation: 10 }}>N</Avatar>
<Avatar
  style={{
    elevation: {
      xs: 5,
      md: 7,
      lg: 9
     }
   }}
>
  N
</Avatar>
```

## Customization

### Jinni UI - Elevation (기본값)

- elevation은 box shadow + (theme=’black’인 경우) white overlay로 구성됨
- white overlay는 `overlayAlpha` prop에 의해 결정되므로, 결국 elevation은 `boxShadow` prop과 `overlayAlpha` prop에 의해 스타일이 결정됨
- 따라서, elevation을 만들려면 `boxShadow` prop과 `overlayAlpha` prop에 동일한 key가 있어야 함
  - ex) boxShadow 10 + overlayAlpha 10 ⇒ boxShadow 10 + whiteOverlay 10 ⇒ elevation 10
- Jinni UI의 Box Shadow와 Overlay Alpha에는 각각 0부터 24까지 총 25개의 동일한 key 값이 존재하므로, 기본적으로 0~24의 elevation이 만들어짐
- `createDesignSystem` 함수의 `boxShadow` prop과 `overlayAlpha` prop을 설정하지 않을 경우, 기본적으로 Jinni UI의 Box Shadow, Overlay Alpha가 설정됨

  ```jsx
  const designSystem = createDesignSystem();
  ```

  ```jsx
  const designSystem = createDesignSystem({
    overlayAlpha: DEFAULT_OVERLAY_ALPHA,
    boxShadow: DEFAULT_BOX_SHADOW
  });
  ```

### Customize Elevation

#### 1) 기존 elevation 값 변경

```jsx
import { OverlayAlphaType } from '@/types/overlay';

const NEW_OVERLAY_ALPHA: Partial<Record<OverlayAlphaType, number>> = {};
let alpha = 0;
for (let level = 0; level < 25; level++) {
  NEW_OVERLAY_ALPHA[level as OverlayAlphaType] = alpha;
  alpha += 0.01;
}

const YELLOW_BOX_SHADOW = Object.fromEntries(
  Object.entries(DEFAULT_BOX_SHADOW).map(([key, value]) => [
    key,
    (value as string).replace(/rgba\(\d+,\s*\d+,\s*\d+/g, 'rgba(100, 100, 0'),
  ])
);

const designSystem = createDesignSystem({
  overlayAlpha: NEW_OVERLAY_ALPHA,
  boxShadow: YELLOW_BOX_SHADOW
})
```

#### 2) 새로운 elevation 속성 추가

1. 새 elevation 속성 추가

   ```jsx
   const designSystem = createDesignSystem({
     overlayAlpha: {
       25: 0.2,
       'floating-action-button': 0.2,
       popper: 0.3,
       toast: 0.4
     },
     boxShadow: {
       25: '0px 12px 15px -7px rgba(0, 0, 0, 0.2), 0px 25px 38px 3px rgba(0, 0, 0, 0.14), 0px 10px 46px 8px rgba(0, 0, 0, 0.12)',
       'floating-action-button':
         '0px 3px 1px -2px rgba(0, 0, 0, 0.2), 0px 2px 2px 0px rgba(0, 0, 0, 0.14), 0px 1px 5px 0px rgba(0, 0, 0, 0.12)',
       popper:
         '0px 3px 5px -1px rgba(0, 0, 0, 0.2), 0px 5px 8px 0px rgba(0, 0, 0, 0.14), 0px 1px 14px 0px rgba(0, 0, 0, 0.12)',
       toast:
         '0px 6px 6px -3px rgba(0, 0, 0, 0.2), 0px 10px 14px 1px rgba(0, 0, 0, 0.14), 0px 4px 18px 3px rgba(0, 0, 0, 0.12)'
     }
   });
   ```

2. 유의할 점

   - 이 경우 `useStyle` 훅이나 JinniUI Component의 style(extended style type)에서는 새로 추가한 typography 속성을 사용할 수는 없음

   ```jsx
   // ⭕ 가능
   import useJinni from '@/hooks/useJinni';

   const App = () => {
     const { elevation } = useJinni();

     return (
       <>
         <p className="elevation-floating-action-button">text</p>
         <p style={{ ...elevation['floating-action-button'] }}>text</p>
       </>
     );
   };
   ```

   ```jsx
   // ❌ 불가
   import useStyle from '@/hooks/useStyle';

   const App = () => {
     const style = useStyle({ elevation: 'floating-action-button' });

     return (
       <>
         <p style={style}>text</p>
         <Avatar style={{ elevation: 'floating-action-button' }}>N</Avatar>
       </>
     );
   };
   ```
