## Z-Index 접근 및 사용

### In CSS

- css 내장 `var()` 함수를 사용해 root 요소에 등록된 z-index 변수 가져와 사용

```css
.classname {
  z-index: var(--jinni-z-index-backdrop);
}
```

### In JSX

#### 1. Inline style에서 CSS 변수 `var()` 사용

```jsx
const App = () => {
  return <p style={{ zIndex: 'var(--jinni-z-index-backdrop)' }}>text</p>;
};
```

#### 2. `useJinni` hook

```jsx
import useJinni from '@/hooks/useJinni';

const App = () => {
  const { zIndex } = useJinni();

  return (
    <>
      <Avatar style={{ zIndex: zIndex['backdrop'] }}>N</Avatar>
      <p style={{ zIndex: zIndex['backdrop'] }}>text</p>
    </>
  );
};
```

#### 3. `useStyle` hook

```jsx
import useStyle from '@/hooks/useStyle';

const App = () => {
  const style = useStyle({ zIndex: 'backdrop' });

  return <p style={style}>text</p>;
};
```

### JinniUI Components

- JinniUI에서 제공하는 컴포넌트 전부 `style` prop(`StyleType`, extended style type)을 받음
- `style` prop의 값은 내부적으로 `useStyle` 훅으로 처리해주고 있음
- 따라서, JinniUI 컴포넌트에 z-index tokens를 적용하고 싶으면 `style` prop에 바로 작성하면 됨

```jsx
<Avatar style={{ zIndex: 'backdrop' }}>N</Avatar>
```

## Customization

### Jinni UI - Z-Index (기본값)

- `createDesignSystem` 함수의 `zIndex` props를 설정하지 않을 경우, 기본적으로 Jinni UI의 Z-Index가 설정됨

  ```jsx
  const designSystem = createDesignSystem();
  ```

  ```jsx
  const designSystem = createDesignSystem({
    zIndex: DEFAULT_Z_INDEX
  });
  ```

### Customize Z-Index

- `createDesignSystem` 함수의 `zIndex` props로 설정된 값은 기존 Jinni UI의 `zIndex`에 덮어 씌워지게 됨
- 즉, `DesignSystemType`의 `zIndex`에 존재하는 key 값을 설정하면 기존 값이 변경되고, `DesignSystemType`의 `zIndex`에 존재하지 않는 key 값을 설정하면 속성이 새로 추가됨

  ```ts
  interface DesignSystemType {
    zIndex: {
      backdrop: number;
      popper: number;
      modal: number;
      drawer: number;
      toast: number;
    }
    ...
  }
  ```

#### 1) 기존 z-index 값 변경

```jsx
const designSystem = createDesignSystem({
  zIndex: {
    drawer: 3000,
    modal: 4000,
    toast: 5000
  }
});
```

#### 2) 새로운 z-index 속성 추가

1.  새로운 z-index 속성 추가

    ```jsx
    const designSystem = createDesignSystem({
      zIndex: {
        'app-bar': 100,
        'floating-action-button': 200
      }
    });
    ```

2.  유의할 점

    - 이 경우 `useStyle` 훅이나 JinniUI Component의 `style`(extended style type) prop에서는 새로 추가한 z-index 속성을 사용할 수는 없음

    ```jsx
    // ⭕ 가능
    const App = () => {
      const { zIndex } = useJinni();

      return (
        <>
          <div style={{ zIndex: 'var(--jinni-z-index-app-bar)' }}>App Bar</div>
          <div style={{ zIndex: zIndex['app-bar'] }}>App Bar</div>
        </>
      );
    };
    ```

    ```jsx
    // ❌ 불가
    const App = () => {
      const style = useStyle({ zIndex: 'app-bar' });

      return (
        <>
          <div style={style}>App Bar</div>
          <Button style={{ zIndex: 'floating-action-Button' }}>FAB</Button>
        </>
      );
    };
    ```
