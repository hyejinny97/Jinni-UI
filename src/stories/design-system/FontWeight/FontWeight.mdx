## Font Weight Tokens 접근 및 사용

### In CSS

- css 내장 `var()` 함수를 사용해 root 요소에 등록된 font-weight 변수 가져와 사용

```css
.classname {
  font-weight: var(--jinni-font-weight-bold);
}
```

### In JSX

#### 1. Inline style에서 CSS 변수 `var()` 사용

```jsx
const App = () => {
  return <p style={{ fontWeight: 'var(--jinni-font-weight-bold)' }}>text</p>;
};
```

#### 2. `useJinni` hook

```jsx
import useJinni from '@/hooks/useJinni';

const App = () => {
  const { fontWeight } = useJinni();

  return (
    <>
      <Avatar style={{ fontWeight: fontWeight['bold'] }}>N</Avatar>
      <p style={{ fontWeight: fontWeight['bold'] }}>text</p>
    </>
  );
};
```

#### 3. `useStyle` hook

```jsx
import useStyle from '@/hooks/useStyle';

const App = () => {
  const style = useStyle({ fontWeight: 'bold' });

  return <p style={style}>text</p>;
};
```

### JinniUI Components

- JinniUI에서 제공하는 컴포넌트 전부 `style` prop(`StyleType`, extended style type)을 받음
- `style` prop의 값은 내부적으로 `useStyle` 훅으로 처리해주고 있음
- 따라서, JinniUI 컴포넌트에 font-weight tokens를 적용하고 싶으면 `style` prop에 바로 작성하면 됨

```jsx
<Avatar
  style={{
    fontWeight: {
      xs: 'thin',
      md: 'medium',
      lg: 'extra-bold'
    }
  }}
>
  N
</Avatar>
```

## Customization

### Jinni UI - Font Weight (기본값)

- `createDesignSystem` 함수의 `fontWeight` props를 설정하지 않을 경우, 기본적으로 Jinni UI의 Font Weight이 설정됨

  ```jsx
  const designSystem = createDesignSystem();
  ```

  ```jsx
  const designSystem = createDesignSystem({
    fontWeight: DEFAULT_FONT_WEIGHT
  });
  ```

### Customize Font Weight

- `createDesignSystem` 함수의 `fontWeight` props에 설정한 값이 그대로 font-weight tokens가 됨

#### 1) 기존 font-weight 중 일부 속성명 변경

```jsx
import { DEFAULT_FONT_WEIGHT } from '@/constants/fontWeight';

const { regular, ...rest } = DEFAULT_FONT_WEIGHT;

const designSystem = createDesignSystem({
  fontWeight: { ...rest, normal: 400 }
});
```

#### 2) 실제 사용하는 font-weight만 저장

```jsx
const designSystem = createDesignSystem({
  fontWeight: {
    regular: 400,
    medium: 500,
    'semi-bold': 600,
    bold: 700
  }
});
```
