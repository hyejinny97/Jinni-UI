# Installation

<br />

## Install Package

```bash
npm install @jinni-labs/ui
```

## Peer Dependencies

`react`와 `react-dom`은 peer dependency이므로,<br />
`@jinni-labs/ui`를 설치하기 전에 해당 패키지들이 먼저 설치되어 있는지 확인해야 합니다.

```json
"peerDependencies": {
  "react": ">=19.0.0",
  "react-dom": ">=19.0.0"
}
```
