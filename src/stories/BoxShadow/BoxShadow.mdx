## Box Shadow Tokens 접근 및 사용

### In CSS

- css 내장 `var()` 함수를 사용해 root 요소에 등록된 box-shadow 변수 가져와 사용

```css
.classname {
  box-shadow: var(--jinni-box-shadow-22);
}
```

### In JSX

#### 1. Inline style에서 CSS 변수 `var()` 사용

```jsx
const App = () => {
  return <p style={{ boxShadow: 'var(--jinni-box-shadow-22)' }}>text</p>;
};
```

#### 2. `useJinni` hook

```jsx
import useJinni from '@/hooks/useJinni';

const App = () => {
  const { boxShadow } = useJinni();

  return <p style={{ boxShadow: boxShadow[10] }}>text</p>;
};
```

#### 3. `useStyle` hook

```jsx
import useStyle from '@/hooks/useStyle';

const App = () => {
  const style = useStyle({ boxShadow: 10 });

  return <p style={style}>text</p>;
};
```

### JinniUI Components

- JinniUI에서 제공하는 컴포넌트 전부 `style` prop(`StyleType`, extended style type)을 받음
- `style` prop의 값은 내부적으로 `useStyle` 훅으로 처리해주고 있음
- 따라서, JinniUI 컴포넌트에 box-shadow tokens를 적용하고 싶으면 `style` prop에 바로 작성하면 됨

```jsx
<Avatar style={{ boxShadow: 10 }}>N</Avatar>
<Avatar
  style={{
    boxShadow: {
      xs: 5,
      md: 7,
      lg: 9
     }
   }}
>
  N
</Avatar>
```

## Customization

### Jinni UI - Box Shadow (기본값)

- `createDesignSystem` 함수의 `boxShadow` props를 설정하지 않을 경우, 기본적으로 Jinni UI의 Box Shadow가 설정됨

  ```jsx
  const designSystem = createDesignSystem();
  ```

  ```jsx
  const designSystem = createDesignSystem({
    boxShdaow: DEFAULT_BOX_SHADOW
  });
  ```

### Customize Box Shadow

- `createDesignSystem` 함수의 `boxShadow` props로 설정된 값은 기존 Jinni UI의 `boxShadow`에 덮어 씌워지게 됨
- 즉, `DesignSystemType`의 `boxShadow`에 존재하는 key 값을 설정하면 기존 값이 변경되고, `DesignSystemType`의 `boxShadow`에 존재하지 않는 key 값을 설정하면 속성이 새로 추가됨

  ```tsx
  interface DesignSystemType {
    boxShadow: {
      0: string;
      1: string;
      2: string;
      ...
      24: string;
    }
    ...
  }
  ```

#### 1) 기존 box shadow 값 변경

```jsx
import { DEFAULT_BOX_SHADOW } from './constants/boxShadow.ts';

const YELLOW_BOX_SHADOW = Object.fromEntries(
  Object.entries(DEFAULT_BOX_SHADOW).map(([key, value]) => [
    key,
    (value as string).replace(/rgba\(\d+,\s*\d+,\s*\d+/g, 'rgba(100, 100, 0'),
  ])
);

const designSystem = createDesignSystem({
  boxShadow: YELLOW_BOX_SHADOW
})
```

#### 2) 새로운 box shadow 속성 추가

1. 새 box shadow 속성 추가

   ```jsx
   const designSystem = createDesignSystem({
     boxShadow: {
       'offset-bottom-left': '-10px 10px 10px -10px rgba(0, 0, 0, 0.3)',
       'offset-bottom-right': '10px 10px 10px -10px rgba(0, 0, 0, 0.3)',
       'offset-top-left': '-10px -10px 10px -10px rgba(0, 0, 0, 0.3)',
       'offset-top-right': '10px -10px 10px -10px rgba(0, 0, 0, 0.3)',
       'inset-all': 'inset 0 0 10px rgba(0, 0, 0, 0.3)',
       'layer-bottom-right':
         '5px 5px rgba(0, 0, 0, 0.4), 10px 10px rgba(0, 0, 0, 0.3), 15px 15px rgba(0, 0, 0, 0.2), 20px 20px rgba(0, 0, 0, 0.1), 25px 25px rgba(0, 0, 0, 0.05)'
     }
   });
   ```

2. 유의할 점

   - 이 경우 `useStyle` 훅이나 JinniUI Component의 style(extended style type)에서는 새로 추가한 box shadow 속성을 사용할 수는 없음

   ```jsx
   // ⭕ 가능
   import useJinni from '@/hooks/useJinni';

   const App = () => {
     const { boxShadow } = useJinni();

     return (
       <>
         <p style={{ boxShadow: 'var(--jinni-box-shadow-inset-all)' }}>text</p>
         <p style={{ boxShadow: boxShadow['inset-all'] }}>text</p>
       </>
     );
   };
   ```

   ```jsx
   // ❌ 불가
   import useStyle from '@/hooks/useStyle';

   const App = () => {
     const style = useStyle({ boxShadow: 'inset-all' });

     return (
       <>
         <p style={style}>text</p>
         <Avatar style={{ boxShadow: 'inset-all' }}>N</Avatar>
       </>
     );
   };
   ```
